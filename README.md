## Home lab and local-first AI

I'd rather run a model than rent one. My desk runs a Ryzen 7 9700X with an RTX 5060 (8GB, so I watch VRAM like a hawk) and 32GB of RAM, with WSL2 Debian on top of Windows 11. llama.cpp serves my local models, and I keep things offline-first: no telemetry, no cloud dependency where I can avoid it.

I self-host the boring-but-useful layer too, a personal memory service and a knowledge graph, plus a text-to-speech voice I cloned for narrating videos. When a tool wants to phone home, I usually replace it.
