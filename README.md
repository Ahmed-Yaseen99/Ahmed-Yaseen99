## What I'm Building

Public tools maintained under [PyPie Studio](https://github.com/PyPie-Studio):

- **[NodeRadar Pro](https://github.com/PyPie-Studio/NodeRadar-Pro)** - Desktop network observability and latency monitoring for Windows, built with C# and Avalonia UI.
- **[unslop-windows](https://github.com/PyPie-Studio/unslop-windows)** - Standalone PowerShell tool to debloat Windows, disable telemetry and turn off Recall without breaking system updates.

Release binaries, docs and specifications are available at [pypiestudio.com](https://pypiestudio.com).
